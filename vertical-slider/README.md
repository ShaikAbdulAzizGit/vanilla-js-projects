# Vertical Slider

A simple and interactive **Vertical Slider** built using **HTML, CSS, and JavaScript**.

The project displays images and their corresponding text in a vertical sliding layout. Users can navigate between slides using the **Up** and **Down** buttons.

## 🚀 Features

- Vertical image slider
- Corresponding text for each image
- Up and Down navigation buttons
- Smooth sliding animation
- Circular navigation
- Full-screen layout
- Simple and lightweight design

## 🛠️ Technologies Used

- **HTML5** – Structure of the slider
- **CSS3** – Styling, layout, and transitions
- **JavaScript** – Slide navigation and DOM manipulation

## ⚙️ How It Works

1. The slider contains multiple image and text sections.
2. Each slide contains an image on the right and related text on the left.
3. JavaScript keeps track of the currently active slide using an index.
4. Clicking the **Up** button moves to the next slide.
5. Clicking the **Down** button moves to the previous slide.
6. CSS `transform: translateY()` is used to move the slides vertically.
7. When the user reaches the first or last slide, the slider loops around.
