# Random Choice Picker

A simple and interactive **Random Choice Picker** built using **HTML, CSS, and JavaScript**.

This project allows users to enter multiple choices and randomly selects one of them. It is a small JavaScript project focused on practicing DOM manipulation, user input, events, and random selection.

## 🚀 Features

- Enter multiple choices
- Separate choices using commas
- Randomly select one choice
- Interactive user interface
- Instant result
- Simple and lightweight design
- No external libraries required

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Application logic and random choice selection

## ⚙️ How It Works

1. Enter multiple choices in the input field.
2. Separate each choice using a comma.
3. The application reads the entered text.
4. The choices are processed and stored.
5. JavaScript randomly selects one of the choices.
6. The selected choice is displayed on the screen.
