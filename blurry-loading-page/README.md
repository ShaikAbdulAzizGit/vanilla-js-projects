# Blurry Loading

A simple loading screen effect built using **HTML, CSS, and JavaScript**.

The project displays a loading percentage from **0% to 100%** while gradually removing the blur from the background image.

## 🚀 Features

- Loading percentage animation
- Background blur effect
- Smooth transition from blurred to clear
- Simple and lightweight

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
